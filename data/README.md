# Dados

O dataset não é versionado por tamanho, licença e boas práticas de repositório.

Coloque `creditcard.csv` em `data/raw/`. O esquema esperado contém `Time`, `V1`–`V28`,
`Amount` e `Class`. Arquivos derivados podem ser gravados em `data/processed/`.

O conjunto usado no projeto é o **Credit Card Fraud Detection**, originalmente
disponibilizado pelo Machine Learning Group da ULB no Kaggle.
