# Como contribuir

Contribuições, sugestões e revisões são bem-vindas.

1. Crie um fork e uma branch descritiva.
2. Instale as dependências com `pip install -r requirements.txt`.
3. Implemente mudanças pequenas e documentadas.
4. Execute `pytest` antes de abrir o pull request.
5. Explique motivação, impacto e como a mudança foi validada.

Nunca inclua datasets, modelos treinados, credenciais ou informações financeiras reais.
Mudanças em métricas devem ser acompanhadas dos parâmetros e da origem dos dados.
