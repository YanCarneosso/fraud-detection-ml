# Segurança

Este projeto é educacional e não processa credenciais ou dados bancários identificáveis.

Não abra uma issue pública contendo chaves, tokens, informações pessoais ou dados
financeiros reais. Para um uso produtivo seriam necessários controles adicionais:
autenticação, criptografia, gestão de segredos, trilhas de auditoria, validação de
dependências e revisão de conformidade.
