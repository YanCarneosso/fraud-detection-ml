# Relatórios

- `fraud_detection_report.html`: relatório executivo local;
- `metrics/`: tabelas e métricas de validação e teste;
- `figures/`: EDA, curvas, matrizes de confusão e SHAP.

O relatório é regenerado automaticamente ao final de `python main.py`. Uma cópia
autocontida é salva em `docs/index.html` para publicação pelo GitHub Pages.
